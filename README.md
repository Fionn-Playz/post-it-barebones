# Post-It Note: Barebones Version
Hello Here is how to install (For chromebooks other OSs not tested)
- open the GitHub page for the repo
- click the 3 dots
- go to "Cast, Save and Share"
- Select "Install Post-It Barebones"
- Press Install
- Size the tab to your liking
- Close it
- Now you are done click on the post it note to reopen!
